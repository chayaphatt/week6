# Week 6 Assignment - Authentication & User Registration System

## About This Assignment

เป็นการพัฒนาเว็บแอปพลิเคชันระบบสมาชิกที่ประกอบด้วยหน้าจอลงทะเบียน (Register) และหน้าจอเข้าสู่ระบบ (Login) ที่เชื่อมโยงการทำงานร่วมกันอย่างสมบูรณ์:
* **HTML5 & CSS3:** การออกแบบโครงสร้างฟอร์มรับข้อมูล เช่น Text Input, Select Gender, Date Picker รวมถึงการตกแต่ง UI ของปุ่มกด (`Register`, `Login`, `Reset`, `Clear`) และจัดเลย์เอาต์ให้สวยงาม ทันสมัย มีมิติละมุนตา
* **JavaScript (DOM & Event Handling):** การเขียนสคริปต์ควบคุมการทำงานฝั่งไคลเอนต์ เพื่อตรวจสอบความถูกต้องของข้อมูล และจัดการเส้นทางการเชื่อมโยงระหว่างหน้าสมัครสมาชิกและหน้าเข้าสู่ระบบ
* **Responsive & Modern Styling:** การปรับแต่งหน้าเว็บไซต์ให้รองรับการแสดงผลบนอุปกรณ์ทุกขนาดได้อย่างราบรื่น พร้อมควบคุมโทนสีและดีไซน์ให้ดูสะอาดตาและเป็นมืออาชีพ

---

## Key Features & Functionality 

* **User Registration Form:** ฟอร์มลงทะเบียนที่รองรับข้อมูลครบถ้วน ทั้งชื่อ-นามสกุล, เพศ, วันเดือนปีเกิด, อีเมล, ชื่อผู้ใช้งาน และรหัสผ่าน พร้อมปุ่มยืนยันและรีเซ็ตข้อมูล
* **Secure Login Interface:** หน้าจอเข้าสู่ระบบที่ออกแบบมาให้ใช้งานง่าย รวดเร็ว พร้อมเชื่อมโยงข้อมูลกับบัญชีผู้ใช้ที่ลงทะเบียนไว้
* **Interactive Validations & Actions:** ระบบแจ้งเตือนและตรวจสอบความถูกต้องของข้อมูลผ่านปุ่มควบคุมที่ตอบสนองต่อผู้ใช้งานแบบเรียลไทม์

---

## Technical Stack

* **HTML5:** โครงสร้างส่วนประกอบหน้าฟอร์ม (`register.html`, `login.html`)
* **CSS3:** ตกแต่งสไตล์ โทนสี พื้นหลังแบบไล่ระดับ และการจัดวางเลย์เอาต์
* **JavaScript (`register.js`, `login.js`):** จัดการตรรกะการทำงานและเหตุการณ์ต่างๆ ภายในฟอร์ม
* **GitHub Pages:** สำหรับเผยแพร่และแสดงผลเว็บไซต์ออนไลน์
